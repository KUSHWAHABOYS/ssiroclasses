# Smart Studio Presenter Pro — Defect & Bug Tracking

Severity definitions:
- **P0**: Data loss, crash, blank screen, ink disappearing, mic turning on by itself, key leak, stuck tool that needs reload.
- **P1**: A specified feature does not work or is unusable on touch.
- **P2**: Works but incorrect / ugly / slow in some edge cases.
- **P3**: Polish, minor visual misalignments, string discrepancies.
